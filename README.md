## Example Format

```sql
SELECT employee_name, department
FROM employees
WHERE status = 'Active';
```

Purpose:

Retrieves the name and department of active employees.

Recall:

* `SELECT` chooses columns.
* `FROM` chooses the table.
* `WHERE` filters records.
